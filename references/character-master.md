# 先固定三视图，再制作动作

新增角色默认先建立正面、侧面、背面全身母版。用户已给合格三视图时检查后复用；调整已有角色不无故重画。

三视图统一身份、体型、配色、花纹、配饰、镜头高度、人物尺度、脚底基线、光照和自然站姿。保留用户原图风格，不把扁平角色强制变成3D。手臂与身体适当分开以便提取，不遮挡关键关节；半身图补全的部分也需要一致性检查。

原图始终是身份依据，不能以生成母版代替原图；同时引用原图与合格母版制作动作，避免只引用上一张结果累积漂移。三张图也可能自相矛盾，必须检查肩宽、肢体粗细、侧面厚度、配饰及尾巴连接，合格后再批量制作。

母版与部件使用同一缩放变换，记录身高、肩关节、肢体尺寸和脚底锚点。裁切不改变角色逻辑尺寸；手臂测量按limb-proportions.md执行，禁止统一按身高30%重造。

本步骤为AI内部流程，正常自动检查后继续，不增加逐张人工确认。工具不可用或身份保真持续不合格时明确阻断。多视图只是2D参考，不能宣称已经得到可任意旋转的真实3D模型。
