# 统一动作与道具标准

本标准覆盖此前“闲置2秒再坐下”的默认设计。每个角色默认直接蹲坐发呆；不先等待2秒站立。只有用户明确要求才改变。角色外形可以变化，状态动作语言保持一致。

| 原生事件/状态 | 默认画面与动作 | 素材检查 |
|---|---|---|
| idle | 无有效视线目标时蹲坐发呆，安静陪伴，可轻呼吸 | 真正坐下的身体结构，不能将站姿压扁 |
| idle＋有效跟随目标 | 站稳，脚和躯干固定，手/爪朝鼠标方向伸出抓取；左右用对应手，上下有合理幅度 | 独立手臂/爪部锚点，不换整张头图、不挪动整个角色追鼠标 |
| busy（普通工作） | 在角色前方敲击透明发光键盘，神情专注、敲击节奏平稳 | 键盘可辨识，爪/手接触键位；相邻帧有真实敲击变化 |
| superbusy（超级繁忙） | 同一副透明发光键盘，更快敲击，忙碌/紧张表情，可少量汗滴 | 道具、角色尺度、位置与普通工作一致，节奏和表情可区分 |
| waiting（任务等待） | 蹲坐等待，抬头看用户，保留原生提醒语义 | 不因和idle同为坐姿而合并其触发条件 |
| voice | 聆听/说话，保留角色特征 | 不强制敲键盘，不用工作态替代语音 |
| completed | 开心举手/小跳，结束按真实当前状态恢复，空闲则回蹲坐 | 不固定回站姿，不把完成常驻 |
| hover/drag | 响应交互，拖动悬空与释放；结束空闲时回蹲坐 | 独立头层不能跳位；拖动不持续叠加闲置呼吸 |

“普通工作/繁忙”映射现有busy，“更忙/超级繁忙”映射现有superbusy，不发明没有事件来源的第三种工作状态。保留原生事件优先级、180秒/10秒切换和中断规则。

## 透明发光键盘

键盘是默认必需工作道具，不必强加实体笔记本电脑或显示器。它是能看清键位的半透明悬浮键盘：键帽轮廓与布局可见，底板透明，适度柔光。背景仍真透明，不能用白底或大块彩色光雾伪装透明。

每个角色版本使用同一固定键盘层。统一缩放、透视、位置与色调，亮度足以在浅/深桌面上辨认但不遮挡脸；按键反馈可独立闪亮。键盘单独固定，手部/爪部敲击，有合理前后遮挡；不要随角色整体抖动、忽隐忽现或逐帧换形。轻微身体动作可独立进行。

逐帧生图容易让键盘漂移，优先创建一次道具层并分层合成到最终渲染，而非要求每帧重新画一个键盘。合成后检查角色手部高度和接触位置。缺工具或动作不合格则阻断，不改为敲空气。

## 鼠标跟随：固定站立，伸手抓取

手臂部件来源、尺寸与肩关节校准必读[母版比例约束](limb-proportions.md)。不得用身高30%等统一比例替代母版实际肢体尺寸，不拉长细化手臂以达到目标。

这是本项目自定义交互表现，复用当前原生指针门控；默认不再通过替换多方向头图表现跟随。有效鼠标目标进入范围时，蹲坐过渡到固定站姿；在原生允许的范围内，手/爪向目标方向伸出并轻抓。目标丢失/null时放手回收，再回蹲坐。精确死区和距离以当前客户端事件为准，不承诺全屏跟随。

站姿头部身份与体积保持，脚底和躯干固定；左右手根据屏幕方向选择，手臂绕肩关节合理旋转/伸展，手爪做张开/收拢，不能拉伸整张人物图片、挪整个人或让手臂脱离肩膀。上方、下方目标通过手臂角度表现，幅度按角色结构限制。中心死区回收双手、避免左右手频繁切换；平滑插值与方向滞回防止抖动。

输入光标有有效目标时保留原生优先级，适用同一伸手表现。hover/drag及工作、超级繁忙、语音、任务等待、完成优先，不被鼠标跟随改回站姿；任务结束时若目标仍有效则站立伸手，否则蹲坐。

需要站姿固定母版、去臂/补齐遮挡的身体、左右臂/爪图层、抓取手型与肩关节锚点。不是只改状态名字就实现，必须生成/提取部件、接入renderer并验证实际动作。头部跟随可作为用户另选的模式，默认关闭，旧模式及素材保留到角色历史版本。

## 适配与验收

每个角色独立校准肩部、手臂与脚底锚点，不沿用其他角色坐标。键盘只在工作状态出现且固定，不跟着指针走。无目标时坐姿与有目标时站姿要有合理过渡，不能混用两套不同头身比例。

同一轮预览必须展示：无目标idle蹲坐；目标进入站稳伸手；左右上下抓取正确且躯干/脚固定；中心死区与快速往返不抖；null目标回坐；busy显示透明键盘且不被指针抢占；superbusy同键盘加速并表情变忙；waiting/voice/完成/拖动抢占；释放及任务结束按当前目标返回。查看105px和放大图、白/深/棋盘背景，分别记录视觉和事件测试结果。
